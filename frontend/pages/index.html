TillKnowIT

A point of sale for spaza shops and tuckshops. This is a demo with made-up shops and people.

Demo only. Do not type real customer or business information here. The demo server may take up to a minute to wake up the first time you sign in. The sign-in code is shown on the screen because no SMS is sent.

  • Manuals and documentationThe solution explained, and a manual for every role: owner, cashier, supplier, parent, field agent, admin.
  • Back officeFor shop owners: products, stock, staff, reports, getting started.
  • TillThe cashier's screen. Set the till up with the codes the owner gets in Staff and tills.
  • Supplier portalCatalogue, orders and deals.
  • AdminFor the platform team: schools, wallets, plans, catalogue lists.
  • Parent appSee a child's wallet and add money.
  • Insights portalArea trends for suppliers.
  • Field agentSet up and verify new shops.
